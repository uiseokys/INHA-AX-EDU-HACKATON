화면 열기

압축을 푼 뒤 index.html을 브라우저에서 열어요. 각 화면은 같은 HTML에서 모바일과 데스크톱 너비에 맞춰 배치돼요. 브라우저 창을 줄이거나 개발자 도구의 기기 모드로 확인할 수 있어요.

폴더 구조를 유지하면 메뉴와 링크가 화면 파일을 찾아가요. 화면들은 2026년 11월 14일을 기준으로 합성 데이터를 넣어 만들었어요.

파일 수정하기

  • 문구와 배치는 screens/의 화면별 HTML에서 바꿔요. 아이콘, 캐릭터, 감정 스티커와 일부 그래프는 HTML 안의 SVG로 들어 있으므로 색과 모양을 직접 바꿀 수 있어요.
  • 공통 색상, 간격, 글꼴, 반응형 배치는 assets/app.css를 수정해요. 이 파일이 브라우저에 직접 적용돼요. 새 CSS는 맨 아래에 추가하고 HTML에서 해당 클래스 이름을 사용하세요.
  • assets/tailwind-source.css에서 기존 디자인 변수와 감정 휠 스타일의 원본을 확인할 수 있어요.
  • 팝업, 감정 휠 조작, 시연 버튼의 이동은 assets/ui.js에서 바꿔요.

시연 동작 확인하기

감정 선택, 강도 조절, 차트 계열 표시, 메뉴 이동, 펼침 패널, 전화 확인창은 브라우저에서 확인할 수 있어요. 저장과 승인 버튼은 준비된 예시 화면으로 이동하고 챗봇은 예시 답장을 보여 줘요. 실제 저장, 외부 AI 호출, 전화 연결은 하지 않아요.

화면은 서버 없이 열 수 있어요. 홈과 각 화면의 Pretendard 글꼴은 인터넷에서 불러오며, 연결할 수 없으면 기기의 기본 글꼴이 적용돼요.
