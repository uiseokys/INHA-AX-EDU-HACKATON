# 쓰담 (SSUDAM)

AI 감정 변화 분석 기반 학교폭력 피해학생 조기 발견 및 지원전문기관 연계 서비스 — 2026 INHA AX-EDU 해커톤 10조

학생이 매일 쓰는 할 일·회고 안에서 10초 감정 체크인을 하고, 규칙 기반 분석으로 감정 변화와 반복되는 고민 주제를 근거와 함께 보여 주며, 학생이 동의한 정보만 상담교사에게 전달해 지원기관으로 연결하는 웹 프로토타입입니다.

> **시연용 프로토타입입니다.** 학생·학교·기관 정보는 모두 합성 데이터이며 실제 정보가 아닙니다.
> 분석 결과는 진단이나 판정이 아닌 참고 정보이고, 로그인·암호화 등 민감정보 보호 기능은 구현되어 있지 않습니다.

## 구성

같은 서비스를 두 가지 방식으로 구현했습니다. 화면과 시연 흐름은 같습니다.

| 폴더 | 구현 | 실행 |
| --- | --- | --- |
| [`ssudam-py/`](ssudam-py) | Python · FastAPI · Jinja2 (서버에서 화면 렌더링, 상태는 로컬 JSON 파일) | `uvicorn app.main:app --reload` → http://localhost:8000 |
| [`ssudam/`](ssudam) | Next.js · TypeScript · Tailwind · Recharts (상태는 브라우저 localStorage) | `npm run dev` → http://localhost:3000 |

설치와 테스트 방법, 폴더 구조, 실제 AI 모델을 붙이는 위치는 각 폴더의 README를 참고하세요.

## 시연 흐름

1. 학생 모드로 접속해 오늘의 할 일을 확인한다
2. 오늘의 감정을 선택하고 기록한다
3. 감정 그래프에 기록이 반영된 것을 확인한다
4. 학생이 상담 지원을 요청한다
5. 상담교사 모드에서 해당 요청을 확인한다
6. 지원기관 추천 화면에서 기관을 연결한다

## 지키는 원칙

- 감정 분석만으로 학교폭력 피해 여부나 정신건강 상태를 진단하지 않습니다.
- 학생이 공유에 동의하지 않은 기록은 상담교사 화면에 표시하지 않습니다.
- ‘위험 학생’ 같은 자동 판정 대신 ‘상담 요청 / 변화 검토 필요 / 지원 진행 중’처럼 지원 절차 단계로만 표시합니다.
