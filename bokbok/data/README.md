# 복복복 시연용 데이터

**이 폴더의 학교·선생님·학생 정보는 모두 시연을 위해 지어낸 합성 데이터입니다. 실제 정보가 아닙니다.**

| 파일 | 내용 | 고치는 사람 |
| --- | --- | --- |
| `class.json` | 가상 학급(1학년 3반), 선생님 2명, 학생 12명과 기본 정보, 학사일정, 초기 알림·상담 시간·상점 상품 | 개발 |
| `records.json` / `records.csv` | 학생별 최근 35일 감정 기록 (감정, 강도 1~5, 감정 단어, 문장). `scripts/generate_data.py` 로 생성 | 개발 |
| `attendance.json` | 학생별 최근 수업일 20일의 합성 출결. 종료된 평일을 수업일로 보고, 가장 최근 수업일이 0입니다. 지각·결석·사유가 확인된 결석을 지정하며 나머지는 출석으로 계산합니다. | 개발 |
| `assessments.json` | 학생별 합성 평가 기록. 과목, 평가 유형, 시험일·결과 공개일의 상대 날짜, 100점 만점 점수를 담습니다. | 개발 |
| `signals.json` | 분석 기준값, 위험 신호 키워드, 고민 주제 키워드, 스스로 돌아보는 질문 | 개발·기획 |
| `help.json` | ‘도움이 필요할 때’ 화면 문구, 긴급·상담 전화번호, 외부 링크 | **기획 (임시 문구 교체 필요)** |
| `chatbot.json` | 복복이 말투(system_prompt), 규칙 기반 대답, 안전 안내 문구 | 기획 |
| `profanity.json` | 복복이 대화에서 `*`로 가릴 욕설·비속어(`words`)와, 욕이 아닌데 겹쳐서 가리지 않을 표현(`allow`) | 기획 |

- `day_offset` 은 오늘을 0으로 한 상대 날짜입니다(-1 = 어제). 앱을 여는 날짜에 맞춰 바뀝니다.
- `school_schedule`의 `date`는 `YYYY-MM-DD` 형식의 고정 날짜입니다. 감정 달력은 이 일정에 학생 본인의 평가일과 결과 공개일을 함께 보여 줍니다.
- 감정 기록의 `shared` 는 학생이 그 문장을 선생님께 보여 주기로 했는지를 뜻합니다. 공유하지 않은 문장은 선생님 화면에 나오지 않고, 위험 표현이 있을 때 ‘감지되었다’는 사실만 알림으로 전해집니다.
- 위험 신호 키워드는 단순 문자열 비교라서 놓치거나 잘못 잡는 경우가 있습니다. 실제 서비스에서는 전문가 검토와 더 정교한 분석이 필요합니다.
