# 복복복 감정 기록 화면: 감정 휠 + 강도 다이얼

2026-11-14 · 크기: 작은 변경 (화면 1개 + 기록에 값 1개 추가)

## 왜

팀이 참고 시안(`ssudam.html`, 원형 감정 휠)의 느낌을 복복복 감정 기록 화면에 원한다.
지금 화면은 카드 3장이 세로로 쌓인 폼이라 "고르는 재미"가 약하다.

## 목표 / 하지 않는 것

- 목표: `/student/record`를 감정 휠 한 화면으로 바꾼다. 배치·애니메이션·문구를 바꾸고 강도(1~5)를 함께 기록한다.
- 유지: 초록 무드, 기획서 감정 5색, 스티커·복복이 그림, 글꼴, 카드·버튼 스타일, 감정 5종과 감정 단어.
- 하지 않음: 감정을 8종으로 늘리기, 분석·알림 규칙에 강도 반영, 다른 화면의 배치 변경.
- 실패로 보는 것: 스크립트가 꺼지면 기록을 못 하게 되는 것, 선생님께 보이는 범위가 안내 문구와 달라지는 것.

## 접근

| 방법 | 장단점 |
| --- | --- |
| **A. CSS 중심 휠 + 다이얼만 스크립트 (선택)** | 기존 라디오·체크박스 폼을 그대로 두고 `:has()`와 CSS 삼각함수로 배치·전환. 서버 코드와 테스트가 거의 그대로이고 스크립트 없이도 기록 가능. 다이얼 드래그만 스크립트. |
| B. 시안처럼 전부 스크립트로 그리기 | 시안 코드를 거의 그대로 쓸 수 있지만 "스크립트 없이도 폼 전송으로 동작"이라는 기존 원칙이 깨지고 접근성(키보드·읽기 프로그램)을 다시 만들어야 함. |
| C. 휠 모양만 흉내 낸 정적 배치 | 가장 빠르지만 가운데로 모이고 퍼지는 애니메이션이 빠져 시안의 느낌이 안 남. |

사용자가 방법을 맡겼고, 기존 원칙과 맞는 A로 간다.

## 설계

- **휠**: 가운데 복복이, 둘레에 스티커 5개(72° 간격). 처음 열릴 때 가운데에서 퍼져 나온다.
- **선택**: 고른 스티커가 가운데로 모이고 나머지는 사라진다. 그 감정의 단어 8개가 둘레로 하나씩 퍼진다. 제목이 "‘슬픔’에 가까운 마음을 골라 주세요"로 바뀐다. "다시 고르기"로 되돌린다.
- **강도 다이얼**: 가운데 스티커를 감싼 고리. 5칸(1~5), 손잡이를 끌거나 칸을 눌러 정한다. 실제 값은 `<input type="range" name="intensity">`가 갖고, 스크립트가 없으면 일반 슬라이더로 보인다. 기본값 3.
- **아래 영역**: 스티커를 고르면 짧은 문장(선택, +5P)·선생님께 보여 주기 스위치·안내가 올라오고, 버튼은 "기록하고 포인트 받기" 하나.
- **저장**: `Record.intensity: int | None`. 1~5로 자르고, 값이 없거나 숫자가 아니면 `None`. 합성 과거 기록은 강도 없음.
- **표시**: 학생 홈 오늘 기록, 학생 리포트 최근 기록, 선생님 학생 상세 최근 기록에 "강도 n". 스티커·단어와 같은 범위로 선생님께 보이므로 안내 문구에 "강도"를 추가한다.

## 만든 사람이 정한 것 (사용자 확인 필요 없음, 고칠 수 있음)

- 강도는 선생님 화면에도 보인다 (스티커·단어와 같은 취급).
- 강도 말: 1 아주 조금 · 2 조금 · 3 보통 · 4 많이 · 5 아주 많이.
- 휠 스타일은 `input.css`에 `wheel-*` 클래스로 둔다 (Tailwind 유틸리티로는 원형 배치를 표현하기 어려움).

## 추가 (같은 날, 사용자 요청)

- **홈보다 감정 휠이 먼저**: 오늘 기록이 없으면 `/student`는 `/student/record`로 보낸다. 기록하면 지금처럼 홈(포인트 적립 창)으로 간다.
- **홈의 스티커 5개 줄 제거**: 감정 휠과 겹치므로 없애고, 기록 전에는 "오늘 마음 기록하기" 버튼 하나만 둔다.
- 만든 사람이 정한 것: 기록 화면 왼쪽 위에 **"나중에 할게요"**를 둔다(오늘 하루만 유효, `state["record_later"]`). 기록을 강제하면 도움·상담이 급한 학생이 홈을 못 보게 되기 때문. 리포트·복복이·상점·도움 메뉴는 기록 없이도 그대로 열린다.

## 검토 뒤 바꾼 것 (같은 날)

- **강도 기본값 3 → 미선택**: 고리는 '?'로 시작하고, 건드리지 않으면 강도 없이 저장한다. 건드리지 않은 3이 선생님 화면에서 일부러 고른 3과 구분되지 않기 때문. 스크립트가 없을 때는 슬라이더 값(가운데 3)이 그대로 저장된다.
- 다른 스티커로 바꿔 기록할 때는 이전 강도를 이어받지 않는다.
- 고리가 받는 터치는 고리 띠와 손잡이뿐이다. 끄는 중에는 5와 1이 서로 바뀌지 않는다.
- '다시 고르기'는 링크(`/student/record?e=none`)라서 스크립트 없이도 동작한다.
